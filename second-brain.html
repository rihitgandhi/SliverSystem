Second Brain

Second Brain carries your accessibility preferences.

Second Brain stores supported preferences like font size, contrast, motion reduction, and spacing, then applies them on websites that allow extension changes.

Problem

Most accessibility failures are site problems.

WebAIM's 2026 automated analysis of the top one million home pages found that 95.9% had detectable WCAG 2 failures.

That data shows why accessibility still needs serious work across the web, and why users are repeatedly forced to adjust, work around, or abandon pages that were not built for them.

95.9% of top one million home pages had detectable WCAG 2 failures.
56.1 accessibility errors per page on average.
1 in 26 page elements had a detectable error on average.
70M+ U.S. adults, more than 1 in 4, report having a disability.

Solution

Second Brain solves repeated personal setup.

Second Brain does not repair missing alt text, missing labels, empty buttons, or broken page code. It focuses on the preferences a person controls directly.

The extension stores supported preferences in the browser and applies them as you move across ordinary websites that allow extension changes.

Browser-level support

One place for the settings a person needs to carry with them.

  • Set font size, contrast, spacing, and reduced motion once.
  • Apply supported preferences where the page allows extension changes.
  • Reduce the repeat setup that happens from site to site.

How it works

Set supported preferences once. Second Brain applies them as you browse.

1

Choose your settings.

Font size, contrast, motion reduction, spacing, and related accessibility preferences start in one place.

2

Visit a website.

Second Brain checks whether supported preference changes can be applied on the page you are visiting.

3

Keep moving.

The extension applies supported preferences on websites that allow extension changes, reducing repeated setup from site to site.

Limits

What Second Brain cannot fix.

Broken page code Second Brain does not repair missing alt text, missing form labels, empty links, empty buttons, or missing document language.
Restricted pages Second Brain is designed for ordinary websites that allow extension changes. Browser-restricted pages and pages that block extension changes may not support every feature.
AI limits Second Brain does not use AI yet. The Checker uses AI to explain detected issues in plain English, but automated checks still cannot prove that a page is fully accessible.

Why not browser settings?

Browser and OS settings still matter. Second Brain is for the gaps between them.

Browser zoom Useful for making a page larger, but it is not a full preference system for contrast, spacing, reduced motion, and navigation support.
Operating system preferences Important when websites respect them. Second Brain gives the user a browser-level place to manage supported web preferences directly.
Second Brain Stores supported accessibility preferences and applies them on sites where extension changes are allowed.

Voice Navigation

Hands-free browsing belongs in the same accessibility system.

Voice Navigation runs on device and lets a user control supported browsing actions with spoken commands.

It is part of Second Brain because reading preferences and navigation support often need to work together.

Within Second Brain

Said naturally. Phrases like "page down", "go back", and "press submit" work too.

  • "click submit" or "click [button or link text]"
  • "scroll down", "scroll up", "scroll to top", or "scroll to bottom"
  • "go to search bar" or "focus [field name]"
  • "go back" or "go forward"
  • "stop listening" or "start listening"
