04 — ARIA
Adding ARIA usually makes it worse

Pages that use ARIA — the markup meant to improve accessibility — average more accessibility errors than pages that don't use it at all. About 35% of ARIA menus introduce new barriers because of how they were implemented.

Source: WebAIM, annual accessibility analysis of the web's top 1,000,000 home pages.
