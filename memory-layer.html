Accessibility Memory Layer

A Chrome extension that remembers your accessibility preferences once and applies them automatically on every site you visit — no more reconfiguring text size, contrast, and spacing page after page.

Reconfiguring every site gets old fast

Most accessibility settings live inside a single website. Bump the text size on one page, switch on high contrast on another, widen the line spacing somewhere else — and none of it follows you. Open a new tab, visit a different site, and you're back to the defaults, doing the same adjustments all over again.

The Accessibility Memory Layer flips that around. Set your preferences once, and the extension carries them with you — automatically, on every site, from the moment the page loads.

What it actually does

Three adjustable settings, saved to your browser and re-applied on every page load:

Text size

Scale body text up or down to a comfortable reading size. Set it once — it holds across every site.

Contrast mode

Choose Default, High-contrast, or Dark-inverted — whichever makes text easiest to read for you.

Line spacing

Loosen up dense paragraphs so lines don't run together, without changing font size.

Live updates

Change a setting while a page is already open and it re-applies immediately — no refresh needed.

How it works

No account, no per-site setup. Just a browser extension quietly doing the same small job everywhere you go:

  1. Install the extension — it adds a small icon to your Chrome toolbar.
  2. Set your preferences once — pick your text size, contrast mode, and line spacing from the popup.
  3. Browse normally — the extension stores your profile locally and injects the right styling into every page you open, automatically, in the background.

Privacy note. Your preferences are stored locally in your browser. Nothing is uploaded or shared — the extension only reads its own saved settings and applies styling to the page you're viewing.
