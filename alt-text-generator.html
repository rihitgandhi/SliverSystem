 Tips for great alt text

                
    
                    
  • Aim for 125 characters or less.
    • 
                    
  • Don't start with "Image of..." — screen readers already announce that.
    • 
                    
  • Add context that isn't already in the surrounding text.
    • 
                    
  • Use empty alt="" for purely decorative images.
    • 
                    
  • For complex images (charts, diagrams), pair short alt with a longer description nearby.
